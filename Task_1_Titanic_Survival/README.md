# Titanic Survival Prediction

## Objective
The objective of this project is to analyze the Titanic dataset and predict whether a passenger survived or not based on various features such as age, gender, ticket class, and fare.

## Dataset
The dataset used in this project is the Titanic dataset obtained from Kaggle.  
It contains information about passengers including age, sex, class, fare, and survival status.

## Steps Followed
1. Loaded and explored the dataset
2. Performed data cleaning and handled missing values
3. Conducted Exploratory Data Analysis (EDA)
4. Visualized important patterns and relationships
5. Built a basic prediction model
6. Evaluated the model performance

## Tools and Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Result
The analysis helped understand key factors affecting survival such as gender and passenger class. A basic machine learning model was built to predict survival outcomes.
